# GitHub Data Migration — Портфолио

## Цель проекта
Перенести существующий React/Next.js проект портфолио из GitHub-репозитория в этот проект и доработать его: добавить недостающие разделы, улучшить визуальное оформление и сделать сайт полностью готовым к публикации.

## Основные возможности

### Шапка сайта (Header)
- **Цель:** Обеспечить навигацию по сайту и фирменный логотип.
- **Описание:** Фиксированная шапка с логотипом (иконка-лапка + текст «Дом с Хвостом») и меню-бургером. Меню содержит пункты: О проекте, Направления работы, Грантовая поддержка, Территория Добрых Дел, Как помочь, Руководитель проекта, Контакты. Пункты ведут на соответствующие блоки по якорям с плавным скроллом. Активный пункт подсвечивается при скролле. Фон шапки — прозрачный/белый, как сейчас.
- **Критерии приёмки:**
  - Логотип (иконка-лапка + текст «Дом с Хвостом») отображается в шапке
  - Меню-бургер открывает список пунктов
  - Пункты меню ведут на соответствующие блоки по якорям с плавным скроллом
  - Активный пункт подсвечивается при скролле
  - Шапка фиксированная (прилипает при скролле)
  - Сайт открывается без ошибок

### Перенос существующего контента
- **Цель:** Перенести все файлы существующего сайта (код, картинки, видео, шрифты, стили, цвета, тексты) из исходного репозитория в этот проект.
- **Описание:** Весь контент и код портфолио копируется в текущий проект с сохранением структуры и работоспособности.
- **Критерии приёмки:**
  - Все страницы и компоненты из исходного репозитория работают в новом проекте
  - Все медиафайлы (картинки, видео) отображаются корректно
  - Шрифты, цвета и стилистика сохранены

### Информация обо мне
- **Цель:** Рассказать посетителю кто я и какие у меня навыки.
- **Описание:** Страница или секция с биографией, навыками, опытом.
- **Критерии приёмки:**
  - Текстовая информация отображается
  - Контактные данные доступны

### Блок «Пространство комплексной помощи» (scroll-storytelling с лапой)
- **Цель:** Эмоционально и визуально рассказать о комплексной помощи животным: от диагностики до реабилитации.
- **Описание:** Scroll-driven storytelling блок с визуальным центром — стилизованной собачьей лапой. Лапа состоит из центральной части (пятка) и 4 пальцев. Каждый палец раскрывает один этап помощи. Блок фиксируется на экране и поэтапно раскрывает смыслы при скролле.
- **Критерии приёмки:**
  - Лапа отображается стилизованно, тёплый брендовый стиль, не мультяшно
  - При скролле блок фиксируется и поэтапно раскрывает 4 пальца
  - Каждый палец визуально увеличивается при активации, рядом появляется текст
  - После прохождения всех 4 шагов блок отпускает скролл
  - Есть индикатор прогресса по шагам
  - На мобильных — облегчённая версия без ломания UX
  - Соблюдены цвета, типографика и стиль проекта

## Цветовая палитра
- **Primary:** #66735A (шалфейно-оливковый) — навигация, заголовки H2, иконки, фон отдельных блоков, спокойные CTA
- **Secondary:** #FFFFFF (белый) — общий фон сайта, карточки, фон секций с текстом
- **Accent:** #B54F45 (кирпично-красный) — кнопки «Помочь/Пожертвовать/Стать волонтёром», важные цифры, активные состояния, короткие эмоциональные вставки

**Правила:**
- 60–70% интерфейса — Secondary, 20–30% — Primary, 5–10% — Accent
- Accent не использовать как основной фон больших секций
- Палитра тёплая, натуральная, доверительная, без холодных corporate-цветов и неона

## Типографическая система
- **Nunito ExtraBold** — H1, H2, H3, hero-заголовки, section titles, короткие сильные фразы
- **Nunito Sans SemiBold** — lead text, card titles, навигация, кнопки, лейблы, подзаголовки
- **Nunito Sans Regular** — абзацы, описания, формы, FAQ, карточки, длинные тексты
- **Caveat** — рукописный акцент (1–2 на экран, не более 5–10% типографики): короткие слова, мини-подписи, цитаты, декоративные фразы

**Ограничения:** Caveat не использовать для длинных абзацев, меню, кнопок, форм, навигации и мелкого текста. Основной интерфейс — чистый, современный, легко читаемый.

## Единый content inset
- В мобильной и десктоп версии используется единый горизонтальный отступ (content inset)
- Все заголовки и описания секций начинаются по одной вертикальной линии
- Эта линия совпадает с началом текста в hero-секции
- **Исключение:** текст внутри карточек блока «Направления работы» (блок 3) не подчиняется этому правилу
